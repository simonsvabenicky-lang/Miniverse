Drop a sound file here named exactly after the gun and it becomes that gun's shot sound.
No code needed — just rebuild.

    AK.wav          Pistol.wav      Shotgun.wav
    SMG.wav         Sniper.wav      ShortCannon.wav   <- ShortCannon is the MINIGUN

.wav or .ogg both work. Keep them SHORT (under ~0.3s) — the minigun fires 22 times a
second, so anything with a long tail turns into mush.

Any gun without a file here falls back to the default shot sound.
